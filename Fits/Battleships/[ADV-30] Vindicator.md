# Vindicator

Close range armor support battleship

## Description

Utilizes webs to ensure that ships, and even some dreads, will apply full damage. This is a base recommended fit, you are highly encouraged to use abyssals to bling this out. Mid-grade amulets are a soft requirement for usage of these in low security space, and are recommended in null security space with the appropriate escape bay frigate.
