# Bhaalgorn

Close range armor support battleship

## Description

Utilizes neuts to shut down major threats. This is a base recommended fit, you are highly encouraged to use abyssals to bling this out. Mid-grade amulets are a soft requirement for usage of these in low security space, and are recommended in null security space with the appropriate escape bay frigate.
